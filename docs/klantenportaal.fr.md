# Portail client

Le portail client est votre espace chez ADM-Concept, le fournisseur de CleanOps. Vous y trouvez notamment vos factures
d'ADM-Concept, vos tickets (questions et signalements à ADM-Concept) et les notes de version.

## Ouvrir le portail

Dans le menu, en bas à gauche, cliquez sur **Portail client**. Le portail s'ouvre dans un **nouvel onglet** ; CleanOps reste
ouvert dans l'onglet où vous étiez. Vous ne devez pas vous reconnecter : CleanOps transmet votre connexion.

Le portail fait partie d'ADM One, la plateforme d'ADM-Concept. Ce que vous y voyez et pouvez faire, ADM-Concept le décide.

## Si le portail ne s'ouvre pas

Au lieu du portail, CleanOps affiche alors un message :

| Message | Ce qu'il signifie |
|---|---|
| Votre compte n'est pas encore connu dans ADM One | Votre utilisateur n'est pas encore lié à ADM One. Signalez-le à ADM-Concept. |
| Votre compte n'a pas encore accès au portail client | Vous êtes connu, mais ADM-Concept n'a pas encore donné accès à votre compte. Demandez-le à ADM-Concept. |
| Le portail client n'a pas pu être ouvert | ADM One n'a pas répondu. Réessayez plus tard. |

Avec **Vers la page d'accueil**, vous revenez en arrière.
