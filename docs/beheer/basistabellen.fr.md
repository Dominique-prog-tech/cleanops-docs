# Tables de base

Les listes de choix que votre entreprise gère elle-même. Elles alimentent les champs de sélection ailleurs
dans l'application : le type sur un contrat, les travaux sur un ordre de travail, la fonction d'un
collaborateur.

<!-- AFBEELDING: l'écran Tables de base avec le choix de liste en haut et quelques lignes -->

!!! note "Ce qui ne figure pas ici"
    Les pays, langues, codes postaux et données BCE proviennent de la plateforme et sont identiques pour tous
    les clients. Vous ne les gérez pas vous-même et ne les trouvez donc pas ici.

## Ouvrir l'écran

Cliquez sur **Administration** en bas du menu, puis sur la tuile **Tables de base**.

## Choisir une liste

En haut se trouve **Liste**. Vous y choisissez la liste de choix que vous consultez :

| Liste | Où vous la retrouvez |
|---|---|
| Types de contrat | le type sur un contrat périodique |
| Travaux | les travaux exécutés sur un ordre ou un bon de travail |
| Statut de planning | une classification libre sur le planning |
| Fonctions collaborateur | la fonction sur une fiche collaborateur |
| Matériel & modes de paiement | matériel et mode de paiement sur un ordre de travail |
| Textes standard d'instructions | textes fixes que vous insérez dans les instructions de travail |

Si vous choisissez **Toutes**, vous voyez toutes les listes ensemble. Une colonne s'ajoute alors, indiquant à
quelle liste appartient chaque ligne.

## Ajouter ou modifier un élément

<!-- AFBEELDING: la fenêtre d'ajout d'un élément, champs remplis -->

Cliquez sur **Nouvel élément**, ou ouvrez une ligne existante. Dans les deux cas, vous obtenez la même
fenêtre.

!!! note "La création n'est possible qu'au sein d'une liste"
    Sur la position **Toutes**, le bouton **Nouvel élément** n'apparaît pas : il n'y a alors aucune liste dans
    laquelle créer l'élément. Choisissez d'abord une liste.

La **description (NL)** est ce que l'utilisateur voit dans les listes de choix.

La **description (FR)** peut rester vide si votre entreprise travaille uniquement en néerlandais. Si vous
travaillez de manière bilingue, complétez les deux — sinon le choix reste vide pour qui utilise
l'application en français.

L'**ordre** détermine la place dans les listes de choix ailleurs dans l'application : plus élevé apparaît en
premier. Vous placez ainsi les types que vous choisissez quotidiennement en tête, au lieu de les laisser
classés alphabétiquement parmi les autres. Si tout est à zéro, le classement est alphabétique.

## Le journal

<!-- AFBEELDING: le journal ouvert, avec quelques lignes de modification -->

À droite de l'écran se trouve une bande portant **journal**. Cliquez dessus et le panneau s'ouvre.

Le journal affiche les modifications de **toutes** les listes de choix ensemble, les plus récentes en
premier : qui a modifié quoi et quand, et de quelle valeur vers quelle autre. Il est en lecture seule.

## Supprimer un élément

Ouvrez la ligne et utilisez **Supprimer** dans la fenêtre. L'élément disparaît des listes de choix mais
subsiste dans la corbeille.

!!! warning "Ne supprimez pas un type déjà utilisé"
    Si vous supprimez un type de contrat figurant sur des contrats existants, cette référence subsiste sans
    valeur lisible. Dans ce cas, donnez-lui un ordre suffisamment élevé pour le reléguer en bas, ou
    renommez-le — et ne le supprimez que lorsqu'aucun contrat ne le porte plus.

## Questions fréquentes

**Un nouveau type de contrat n'apparaît pas dans la liste de choix d'un contrat.**
Vérifiez que vous l'avez créé dans la bonne liste. Sur la position **Toutes**, chaque ligne indique à quelle
liste elle appartient.

**Mes choix quotidiens figurent en bas des listes.**
Attribuez-leur un **ordre** plus élevé. Les listes de choix trient sur l'ordre avant de trier
alphabétiquement.

**Chez nous, la colonne française est partout vide.**
Ce n'est pas une erreur : qui travaille uniquement en néerlandais n'a pas besoin de la remplir. Elle n'est
utilisée que lorsqu'un utilisateur ouvre l'application en français.
