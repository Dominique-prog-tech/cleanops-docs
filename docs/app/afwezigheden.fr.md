# Absences

Sous **Absences**, vous voyez dans l'application qui est absent aujourd'hui et quelles demandes de congé attendent le
bureau. L'écran demande le droit sur les [Demandes de congé](../verlofaanvragen.fr.md) (voir
[L'application pour le bureau](kantoor.fr.md)). Approuver ou refuser se fait dans CleanOps sur l'ordinateur.

Si vous travaillez vous-même aussi sur le terrain, vos propres congés figurent à part dans le menu, sous **Congés** (voir
[Congés](verlof.fr.md)).

## Ouvrir l'écran

Ouvrez le menu et touchez **Absences**.

## Absents aujourd'hui

En haut figurent les absents du jour, avec le type de congé, la description et de quand à quand. C'est la même liste que
*Absents aujourd'hui* sur le tableau de bord : qui ne travaille pas aujourd'hui selon son régime de travail n'y figure pas,
même si son congé couvre aujourd'hui.

Si CleanOps n'a pas pu lire les jours fériés, l'écran indique que le nombre n'est pas certain.

## Les demandes de congé

Choisissez sous *Absents aujourd'hui* :

- **À traiter** : les demandes sur lesquelles le bureau doit encore décider. L'écran s'ouvre ainsi. Ce qui commence en
  premier figure en haut.
- **Toutes (aussi traitées)** : en plus, les demandes approuvées, refusées et retirées, la décision la plus récente en
  premier.

Chaque demande indique le collaborateur, la période, le nombre de jours, le type et le statut : *En attente* en orange,
*Approuvé* en vert, *Refusé* en rouge. En dessous, la remarque du collaborateur, en cas de refus la raison, et qui a traité
la demande.

## Questions fréquentes

**Je veux approuver une demande.**
Ce n'est pas possible dans l'application. Faites-le dans [Demandes de congé](../verlofaanvragen.fr.md) sur l'ordinateur.

**Absences ne figure pas dans le menu.**
Votre rôle n'a pas le droit sur les demandes de congé, ou votre entreprise a désactivé la fonction Congés (voir
[Gestion de la plateforme › Fonctions](../beheer/functies.fr.md)).
